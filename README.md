# 🌐 Professional Website

A premium, modern portfolio and business website designed for high-end digital experiences.

## ✨ Features
- **Modern Aesthetics**: Sleek dark mode with glassmorphism and indigo/violet gradients.
- **Dynamic Animations**: Smooth scroll-reveal effects using Intersection Observer.
- **Responsive Design**: Fluid layouts that adapt to all screen sizes.
- **Interactive Elements**: Custom cursor follower and glass-styled cards.
- **Optimized for SEO**: Semantic HTML structure and descriptive metadata.

## 🚀 Technologies Used
- HTML5 (Semantic)
- CSS3 (Vanilla, Custom Variables)
- Javascript (ES6+)
- Google Fonts (Outfit)

## 📁 Structure
- `index.html`: Core structure and content.
- `style.css`: Design system and layout styles.
- `script.js`: Interactive logic and animations.
